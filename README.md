# Crab Desk

A panel for Claude Code in the Claude desktop app. It shows your projects, the chats that need you, and how much time you've spent in Claude Code today. A pixel-art picture shows a crab for each chat: crabs at work for chats that are running, crabs on a break for chats waiting on you. Pick the scene: Studio, Ocean or Camp.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install crab-desk --marketplace ThomasChenTheButt/crab-desk
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```bash
claude plugin install crab-desk --marketplace ThomasChenTheButt/crab-desk
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `ThomasChenTheButt/crab-desk`, then Add plugin.

Open the panel with `/terminal`. The usage view needs `python3` on your Mac.
